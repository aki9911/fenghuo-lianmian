# 发布与更新网页版

在线试玩：https://aki9911.github.io/fenghuo-lianmian/

玩家无需安装 Godot 或下载可执行文件。建议桌面键鼠，浏览器需支持 WebGL 2；首次打开会加载约 53 MB 游戏资源。

## 后续修改

日常继续编辑原工作区 `game/project.godot`。`publish/fenghuo-lianmian` 是独立的发布用 Git 仓库，不要把其他项目复制进去。

1. 完成代码或数值调整，并运行相应 Godot 测试。
2. 在原工作区运行 `./tools/export_demo.ps1 -WebOnly`。它按白名单复制游戏和公开策划，移除编辑器远程控制插件，导出浏览器版；不会覆盖本地私人文件。
3. 在 GitHub Desktop 选中 **fenghuo-lianmian**，核对变更，提交并 Push。也可在该独立仓库用 Git 提交与推送。
4. 等待仓库 Actions 的 **Build playable demo and deploy Pages** 成功。它重新导出最新源码并发布；试玩 URL 不变。

网页首页和操作说明位于发布仓库的 `web/index.html`。完整 `.wasm` 与 `.pck` 必须配套，不能只上传 `game.html`。GitHub Pages 已设置为 GitHub Actions 部署。
