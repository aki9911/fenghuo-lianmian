边镇守御 · v0.5

烽火连绵

守住一座镇。
让每一次抵抗，都留下结果。

作为边镇指挥官，你需要筹备物资、调配人手、布置五支分队，并亲自参加防守。守城失利后，护送军民撤离，保全下一次抵抗的力量。

浏览器试玩 →

桌面键鼠体验。浏览器首次加载约 53 MB；支持 WebGL 2 的浏览器可运行。无需安装游戏或 Godot；首次打开会由浏览器加载游戏资源。

实时镇务 → 资源筹备 → 暂停布阵 → 实时防守 → 撤离与战报 → 战后恢复

先从这里开始

  • 点击游戏画面，W A S D 移动，鼠标转向；Esc 释放鼠标。
  • 走近建筑入口按 E：工程营修缮、医棚救治、军需作坊制作。
  • M 查看全镇。到指挥所接敌，选队后点击地图立即布阵。
  • 开战后 H 打开军令轮盘，1–5 选队，再选择跟随、驻守或推进。
  • 空格或左键攻击；城外 Q 退守木墙；E 破坏粮仓、操作床弩或撤离。

这一版能玩什么

  • 100 居民与 50 军人的镇务、雇佣、物资制作和修缮。
  • 城外、木墙、巷战、撤离四阶段；敌军持续补充，以士气驱动战局。
  • 第三人称、实体碰撞、即时布阵和五队军令。
  • 本机战报和模拟邻镇物资支援。

全服战区、真实玩家互助、动态故事与长期排行榜尚未接入。当前不含正式动作技能与动画。

设计出发点

以《燕云十六声》版本内容消耗后的持续参与需求为设计假设，参考长期战役调度与阶段防守，探索“个人镇务—共同战果—世界反馈”的 PvE 活动方向。长期构想是由官方调度攻势、玩家集体抵抗，以战区结果推动后续故事；当前 Demo 先验证单人循环。

项目使用 Codex、多 Agent、Excel 配置和 Godot MCP 推进需求拆解、原型实现与回归验证。策划文档、可编辑角色场景和共用行为脚本在独立仓库中持续维护。
